            Impostazioni

            Collegamento a GitHub

            I giochi sono salvati nei file data/games.json e data/upcoming.json della tua repository. Per poter aggiungere, modificare ed eliminare giochi serve un token personale GitHub (vedi README). Il token resta salvato solo in questo browser.

            Copertine

            Cerca automaticamente la copertina dei giochi che non ce l'hanno ancora (dati da Wikipedia/Wikidata). Se una copertina è sbagliata, apri il gioco → Modifica → “Cerca dati” e scegli quella giusta.

            Backup

            Scarica una copia di tutti i dati o ripristinala da un file di backup.
